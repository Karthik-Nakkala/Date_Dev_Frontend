## ⚡ FIRE IT UP (QUICK START)

Ready to launch Date_Dev on your local machine? Follow these simple steps:

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/Karthik-Nakkala/Date_Dev_Frontend.git
cd Date_Dev_Frontend
```

### 2️⃣ Install Dependencies
```bash
npm install
```

### 3️⃣ Set Up Environment Variables
Create a `.env` file in the root directory:
```env
VITE_BASE_URL=http://localhost:7777
```

### 4️⃣ Run the Dev Server
```bash
npm run dev
```

> 🔥 Open [http://localhost:5173](http://localhost:5173) in your browser and experience the energy!
